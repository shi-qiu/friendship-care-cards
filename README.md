# Friend Cards

A warm, mobile-first deck of care gifts for a new mother, built with plain HTML,
CSS, and JavaScript. Redeemed cards are saved in the browser when local storage
is available.

## Local preview

From this directory, start any static file server:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## GitHub Pages

Push these files to a GitHub repository, then open **Settings → Pages**. Under
**Build and deployment**, choose **Deploy from a branch**, select the branch
containing the site (usually `main`) and the `/ (root)` folder, then save.
GitHub will show the public site URL when publishing finishes.
